## NeoST 0.6.5 — the last release on NeoST's own Moira core

The last release on the current 68000 core: the next one switches to the POM68K core. 0.6.5 stays the fallback version until the new core has proven itself.

Try it in the browser, nothing to install: **[habib256.github.io/neost](https://habib256.github.io/neost/)** (EmuTOS, free content only; the same build ships as `NeoST-0.6.5-web-wasm.zip`).

**Rewind**
- One state per second kept in memory; Ctrl+Alt+R steps back (desktop GUI, web, Android; off by default).
- Floppies rewind with the machine, host image file included.

**Accuracy**
- Closure no longer shows stray black frames in its big logo (STOP wake-up now lands on the 68000's even cycle grid), and its picture no longer flickers in the borders: medium-resolution frames that follow an open-border frame keep their borders.
- STE DMA sound: end-of-frame interrupt dated at the last word fetched, RESET clears the sound registers as the ST-4081 schematic says.
- 4-pixel LO/MED/LO hardscroll and mid-line `$FF8264` writes follow the Shifter model.
- 22-bit DMA sound counter, CPU reads of `$0-$7` return the ROM.
- IKBD command `$19` and serial BREAK handling follow the 6301 ROM and the chip datasheets.
- Selectable master crystal (`--quartz`, Machine page), from measurements on real STs.

**Games**
- Lemmings played through to level 2; Pacemaker, Obsession and Extase join the replays checked against Hatari: 27 in total.
- Sound of 95 titles compared against Hatari.
- TOS 1.06 US boots; TT/Falcon TOS images are refused cleanly.

**Usability**
- Picking a machine model in the configuration also picks a TOS from `roms/` that runs it (same family and country when possible).
- Adaptive zoom: no more black band above Enchanted Land.
- Twelve more country keyboard layouts.
- Menu disks named from the CompDisks catalogue (Floppy page and kiosk).
- Bitmap explorer in the debugger.
- MIDI: keyboard split zones per host input, MIDI Time Code output.
- Optional domain allow-list for the built-in NAT and the modem.
- The STinG + EtherNEC boot disk now ships in the packages.
- Android: ROM page and dongles page; long HOG blits no longer freeze the web and Android builds.

**Robustness**
- Two bug hunts: forged disk images, per-process GEMDOS host drive state, strict headless options, Windows files above 4 GiB.

**Save states**: format v67 (v59 in 0.6.4); older states do not load.

Packages ship with their licences (`GPL-3.0.txt`, `GPL-2.0.txt`, `THIRD-PARTY.txt`) and contain no Atari ROM: EmuTOS is the default.
