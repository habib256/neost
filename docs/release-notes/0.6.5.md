## NeoST 0.6.5

The last version before the integration of the future 68000 Moira core, with 68020/68030/68040 CPUs, a JIT and an MMU, which will open the way to the TT and the Falcon. 0.6.5 stays the reference version on the current core.

Try it in the browser, nothing to install: **[habib256.github.io/neost](https://habib256.github.io/neost/)**.

**What's new**
- **Rewind**: Ctrl+Alt+R steps back in time, floppies included (off by default).
- **Accuracy**: Closure runs clean (no stray black frames, no flickering borders); STE DMA sound, Shifter hardscroll, IKBD and serial chips closer to the real hardware; selectable master crystal.
- **Games**: Lemmings, Pacemaker, Obsession and Extase join the games replayed against Hatari (27 in total); TOS 1.06 US boots.
- **Usability**: picking a machine model also picks a matching TOS, and picking a TOS adjusts the model; a quieter terminal (`--verbose` for the full log); adaptive zoom fixed on Enchanted Land; a warm reset or a config change no longer scrambles Spectrum 512 pictures; twelve more keyboard layouts; keyboard joystick fires with right Alt/Option instead of right Ctrl (MacBooks have none); joystick dongles offered only on the port their game reads; bitmap explorer in the debugger; MIDI split and Time Code.
- **Robustness**: two bug hunts (disk images, GEMDOS host drive, Windows files above 4 GiB).

**Save states**: format v67; states from 0.6.4 do not load.

Packages contain no Atari ROM: EmuTOS is the default. Licences included.
