## NeoST 0.6.5

The last version before the integration of the future 68000 Moira core, with a 68020/68030/68040 CPU and JIT, which will open the way to the TT and the Falcon. 0.6.5 stays the reference version on the current core.

Try it in the browser, nothing to install: **[habib256.github.io/neost](https://habib256.github.io/neost/)**.

**What's new**
- **Rewind**: Ctrl+Alt+R steps back in time, floppies included (off by default).
- **Accuracy**: Closure runs clean (no stray black frames, no flickering borders); STE DMA sound, Shifter hardscroll, IKBD and serial chips closer to the real hardware; selectable master crystal.
- **Games**: Lemmings, Pacemaker, Obsession and Extase join the games replayed against Hatari (27 in total); TOS 1.06 US boots.
- **Usability**: picking a machine model also picks a matching TOS; adaptive zoom fixed on Enchanted Land; twelve more keyboard layouts; bitmap explorer in the debugger; MIDI split and Time Code.
- **Robustness**: two bug hunts (disk images, GEMDOS host drive, Windows files above 4 GiB).

**Save states**: format v67; states from 0.6.4 do not load.

Packages contain no Atari ROM: EmuTOS is the default. Licences included.
