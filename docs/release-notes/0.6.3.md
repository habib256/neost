## NeoST 0.6.3 — NetUSBee USB and built-in networking

- **NetUSBee USB devices:** connect a virtual USB keyboard, mouse or disk image
  to either port. Hot-plug devices in Configuration → Network, save them in
  profiles, or use `--usb1` / `--usb2` in the headless runner. USB4TOS drivers
  have been tested with keyboard input, mouse packets and file reads/writes.
  Disk images support read-only mounting. Native ST-side USB drivers are required.
- **Built-in NAT:** IPv4/IPv6 networking without libslirp or GLib, including
  DHCP, DNS, TCP/UDP and explicit port forwarding. STinG/ENEC can load HTTP pages.
- **Hardware accuracy:** further CPU, video, floppy, serial and sound fixes,
  backed by chip documentation and regression benches. Vroom Elite starts on STE.
- **Issue #44:** missing Atari ROMs are reported as skipped Spectrum 512 tests;
  available machines still detect regressions, and partial runs cannot overwrite
  the reference set.

**Save states use format v59. Older states cannot be loaded.** Disk image contents
remain external to save states. USB passthrough and isochronous transfers are not
implemented.

macOS packages remain unsigned by Apple: right-click the app and choose Open on
first launch.
